## v0.1 单SKC手动利润计算器 — 初始开发完成

### 概述
在 `E:\EcommerceSkills\Profit accounting-Auto\` 新建了利润管理软件的最小可用版本，
纯手动输入、自动计算、SQLite持久化、历史管理。不依赖AI、OCR、1688等。

### 完成的功能
1. **Windows GUI 界面**（tkinter）：新商品测算 + 历史记录两个标签页
2. **全部手动输入字段**：商品名称、成本、裸件/包装数据、物流费用、售价、利润率、推广比例、备注
3. **自动计算**：体积重、计费重量、头程、总物流成本、总成本、利润、利润率、建议售价、人民币/美元换算
4. **售价/利润率双向联动**：通过 `_last_modified` 追踪避免循环
5. **SQLite 持久化**：products、product_snapshots、config 三张表
6. **历史管理**：搜索、打开编辑、删除（含确认）
7. **配置持久化**：汇率、头程单价、固定服务费、默认尾程 — 存数据库，重启保留
8. **输入校验**：空值、非数字、负数、汇率为零、利润率异常 — 返回 None 不崩溃
9. **模块分离**：calculation/ database/ config/ ui/ 完全独立
