# 数据与算法说明

## 校准库
- 79 条历史记录
- 79 张嵌入商品图片
- 实际头程费用、历史 AI 估算、补全重量/尺寸、包装标签

## 处理原则
1. 先使用用户明确提供的实重和尺寸。
2. 体积重按 `/8000`，与实重取高。
3. 没有实测信息时，从图片哈希和商品文字中找相似记录。
4. 历史实际费用不直接替代当前规则，而是形成“历史修正系数”和参考区间。
5. 修正后的计费重再分别套用深圳、义乌最新规则。
6. 输出两家费用，并自动推荐当前估算更低的一家。
7. 在 0.2kg 左右，两家货代成本可能随误差区间发生切换，因此会提示复核。

## 风险控制
- 历史同款不同批次可能费用不同。
- 图片无法可靠提供精确重量和尺寸。
- 所以工具默认输出区间，而不是伪造一个看似精确的单值。
