## 模式1：利润核算

最终可见回复严格由五部分组成：商品摘要 → 第一张表 → 参数摘要 → 第二张表 → 推算句。

### 商品摘要

与模式2完全相同。

### 第一张表

与模式2完全相同，仍展示四种头程方案。

### 参数摘要

```
当前参数：汇率1 USD＝¥{汇率}；售价低于$29时享受SHEIN补贴$2.99；尾程${尾程USD}＝¥{尾程RMB}；目标利润率按成本{目标利润率}%；活动预留{活动预留率}%；采用最低的{最低方案}总头程¥{最低总头程}。
```

### 第二张表（一行七列）

| 国内成本（¥） | 总头程（¥） | 尾程（¥） | 无活动售价（USD） | 无活动利润（¥） | 活动后售价（USD） | 活动后利润（¥） |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| ... | ... | ... | ... | ... | ... | ... |

第二张表禁止增加：方案列 / 总成本列 / 补贴列 / 活动预留列 / 利润率列 / 推荐列 / 第二行或四行方案

### 推算句

```
推算：国内成本为采购价¥{采购价}＋国内运费¥{国内运费}；采用{最低方案}后核算成本为¥{总成本}；无活动售价为${无活动售价}，无活动利润为¥{无活动利润}；活动后售价为${活动后售价}，{满足/不满足}SHEIN补贴条件，活动后利润为¥{活动后利润}。
```

## 数值格式

- 尺寸：使用×，整数不显示 .0
- 重量：g，四舍五入到整数
- 费用：两位小数
- USD 售价：`$` 前缀，两位小数
- 利润：两位小数
- 汇率保留配置精度
- 所有计算先用未舍入数值，只在最终展示时舍入
- 补贴条件使用未舍入的 USD 售价判断

---

## 缺失数据

- 采购价或国内运费缺失：显示"未识别"；第二张表单元格显示"无法计算"
- 推算句固定："推算：头程已完成；利润部分因采购价或国内运费缺失无法计算。"
- 数量缺失默认 1 件

## 确定性程序渲染

所有输出由 `logistics_cost/output_renderer.py` 中的 `render_head_only()` 或 `render_profit()` 函数生成。Agent 不得手工拼接表格，不得在程序输出后改写/总结/解释/增加/删除/调整顺序。日常核算最终回复必须逐字输出 renderer 结果。
