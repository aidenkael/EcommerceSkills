# START_HERE_FOR_AGENT.md

这是物流 2.0 工具根目录。

## Agent 首次读取

1. 读取项目 `AGENTS.md`。
2. 读取 `SKILL.md` 中与当前任务相关的部分。
3. 日常图片核算不运行环境检查、Git、测试或报告。
4. 新对话第一次核算时询问：
   1. 利润核算
   2. 仅头程
5. 模式只在当前对话有效。
6. 四项默认参数从 `config/local_user_preferences.json` 读取。
7. 核算完成后严格按固定表格输出。

## 首次输出

1. 利润核算
2. 仅头程

回复1或2。
