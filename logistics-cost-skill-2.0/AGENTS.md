# AGENTS.md (simple-v2.1)

- 当前项目是电商单件物流成本核算 Skill。
- 商品图片触发核算时，Codex 通过 Read 工具读取像素，按 `examples/socks_ai.json` 格式输出 AI JSON。
- 物流公式和费率只从 `config/logistics_config.json` 读取。
- AI 输出的包装方案必须同时提供 normal 和 conservative 两档。
- Python 负责：证据仲裁、软品检查、重量修正、确定性头程计算。
- 软品展开尺寸不得作为包装尺寸；体积重 > AI 净重 ×3 时自动忽略。
- 用户可信净重使用净重 + 0.05kg；低可信重量不得进入可信流程。
- 1688 链接只保存，不访问网页。
- 参数修改必须显示原值和建议值并由用户确认；使用 Git 管理。
- 保持实现简洁，只修改任务所需内容。

## GitHub 提交与复审规则

每完成一个独立开发任务后：

1. 运行与本次修改相关的测试和完整性检查。
2. 确认测试通过后，再提交并推送到 GitHub。
3. 一个提交只包含一个明确任务，禁止混入无关修改。
4. 提交信息使用简洁中文，准确说明本次修改内容。
5. 较大修改应使用独立分支，必要时创建 Pull Request。
6. 不提交密钥、Token、账号、缓存、日志、临时文件、数据库测试数据或其他敏感内容。
7. 推送完成后，报告：
   - 当前分支；
   - 最新 commit；
   - 修改的文件；
   - 主要修改内容；
   - 测试结果；
   - 已知问题或尚未完成的内容。
8. 未通过测试时，不得将结果描述为"已完成"；可以提交修复中的版本，但必须明确标注当前状态。
9. 除非用户明确要求，不得强制推送、覆盖远程历史或修改其他分支。
