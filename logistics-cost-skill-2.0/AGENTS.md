# AGENTS.md — 物流成本核算 Skill v2.1

## 项目目标
电商单件跨境物流头程成本核算 Skill。Codex 读取商品图片 → 输出 AI JSON → Python 确定性计算。

## 对话运行协议

### 模式选择

新对话中，如果用户只上传图片而没有明确说明模式，Agent 必须只回复：

```
请选择本次模式：

1. 正常核算
   识别商品并输出正常档、保守档、两家货代费用和推荐结果。

2. 仅校准头程
   根据用户提供的实际纯头程和实际货代，对比估算误差并形成校准分析。

请回复 1 或 2。
```

输出菜单后立即停止，不得提前识图、计算或输出商品分析。

### 模式规则

- 用户明确说"正常核算"或"仅校准头程"时，直接进入对应模式，不再询问。
- 用户选择后，本对话持续记住该模式。
- 后续每次上传图片不重复询问。
- 用户说"切换模式"时重新显示菜单。
- 新建对话不继承上一个对话的模式。

## 区分：开发任务 vs 工具日常使用

### 开发任务
修改代码、规则、配置或文档 → 执行 Git 检查、测试、报告和提交流程。

### 工具日常使用
用户上传图片进行核算或校准 → 不检查 Git、不创建分支、不运行测试、不生成开发报告、不输出文件扫描和命令执行过程。

## 业务规则

- 物流公式和费率只从 `config/logistics_config.json` 读取，不写死任何数值。
- AI JSON 格式参照 `examples/socks_ai.json`，包装方案必须提供 normal 和 conservative 两档。
- Python 负责：证据仲裁、软品检查、重量修正、确定性头程计算。
- 软品展开尺寸不得作为包装尺寸；体积重 > AI 净重 ×3 时自动忽略。
- 用户可信净重使用净重 + 0.05kg；低可信重量不得进入可信流程。
- 1688 链接只保存，不访问网页。
- 参数修改必须显示原值和建议值并由用户确认。
- 保持实现简洁，只修改任务所需内容。
