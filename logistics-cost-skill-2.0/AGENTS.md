# AGENTS.md — 物流成本核算 v2.2

## 任务分类
**开发任务：** 修改代码/规则/配置/文档 → Git检查、测试、提交。**日常核算：** 上传图片 → 不检查Git、不测试、不写文件、不写MEMORY。

## 模式（仅当前对话有效）
两种模式：1. 利润核算 / 2. 仅头程。新对话第一次核算只输出模式菜单并停止。已选后后续商品沿用。禁止从local_user_preferences.json/MEMORY/历史对话读取模式。

## 利润模式参数门禁
利润模式在图片理解前读取本地默认参数（汇率/尾程USD/目标利润率/活动预留）。第一次缺参数时一次性询问全部缺失项并停止。用户提供后保存到local_user_preferences.json，后续只修改时更新。

## 每商品快速路径
```
确认SKU和数量→一次图片理解→输出紧凑结构签名→生成正常/保守包装→一次本地计算→最终格式化
```
每个商品最多1次图片理解+1次计算。仅异常时允许1次重估。缺参数不阻断。

## 当前SKU优先
证据优先级：用户明确说明>当前高亮SKU/数量>规格参数>validated档案>通用规则>AI推测。禁止用同页套包/其他颜色覆盖当前单包。

## 物理包装总原则
区分展示与运输状态，判断刚性主体/可折部件/可拆附件/压缩/嵌套/保护。展示尺寸≠运输包装尺寸。

## 正常档/保守档
正常档：最可能普通代发包装。保守档：合理偏高成本场景，只调整不确定因素，不机械放大。

## 案例库触发条件
日常核算不读案例库。仅反馈/异常/校准请求时读最多3个。

## 固定输出
仅头程：1句+1表+1句推算。利润核算：1句+2表+1句参数+1句推算。禁止小结/临界点/案例引用/模式说明/风险段落/MEMORY提示。

## 禁止
日常核算禁止：写MEMORY/日志、修改AGENTS/SKILL/knowledge/、保存AI JSON/Markdown、执行Git、联网、访问1688链接。
