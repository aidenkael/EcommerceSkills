## 全部修改

### 数据模型

- Schema 从 v2 升级到 v3。
- `products` 保存最近一次规则、最近一次计算结果、计算结构版本和计算时间。
- `product_snapshots` 继续保存首次不可变快照。
- 新增原子保存接口，新商品、当前状态和首次快照同事务提交。

### 规则与计算

- 当前商品规则与首次还原规则使用独立读取路径。
- 商品重新打开使用最近一次保存规则；还原只使用首次快照规则。
- 保存结果统一为明确字段：体积重、计费重、头程、总物流、总成本、净利润、净利率、建议售价和折合美元。
- 历史加载优先展示保存结果，不再无条件套用当前公式。
- 体积重除数作为实际公式参数。
- 规则差异比较成为纯函数，覆盖 `None` 与已有值之间的变化。

### 历史列表

- 优先使用保存的净利率。
- 旧记录只有在商品成本、国内运费、三段物流费用和售价全部完整时才兼容计算。
- 不再将缺失商品成本或国内运费当作零。

### 迁移

- 补建缺失的 `products` 和其他核心表。
- 补齐旧快照全部规则列和旧商品可安全添加的业务列。
- 旧业务规则版本 1 升级后可读取版本 2。
- 高于当前支持版本的数据库拒绝打开。
- 迁移失败回滚并恢复迁移前备份。
- 提交前检查必需字段、SQLite 完整性和外键。
- 当前版本数据库正常打开时也执行结构与完整性检查。

### 文档

- README 已重写，移除乱码和过期设置说明。
- 补充当前状态/首次快照、严格缺失、计算公式、精度、迁移和已知边界。
