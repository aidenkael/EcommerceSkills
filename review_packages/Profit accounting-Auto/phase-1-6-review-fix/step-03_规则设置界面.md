# Step 03: 规则设置界面

## 目标
规则编辑器使用中文映射下拉框，增加防丢失保护和归档保护。

## 修改文件
- `ui/main_window.py`（`ProfitRulesDialog` 完整重写）

## 具体修改

### 1. 中文映射下拉框
将 6 个枚举字段从 Entry 改为 Combobox，中文显示 ↔ 内部英文值映射：
- 条件字段：无条件/最终售价（美元）/最终售价（人民币）/商品成本（人民币）/物流成本（人民币）
- 比较方式：小于/小于等于/大于/大于等于/等于
- 调整方向：增加收入/增加成本
- 调整类型：固定金额/百分比
- 币种：美元/人民币
- 百分比基数：最终售价人民币/商品成本人民币/物流成本人民币

### 2. 字段联动
- 无条件 → 禁用比较方式和阈值
- 固定金额 → 禁用百分比基数，启用币种
- 百分比 → 启用百分比基数，禁用币种，标签改为"比例 (%)"

### 3. 增加 description 字段
规则表单增加"说明"输入框，存入数据库 description 列。

### 4. 防丢失保护
`_check_dirty()` 方法：选择另一条规则/新增/归档/关闭时检查未保存修改，弹窗三选一：
- 保存并继续
- 放弃修改并继续（重新载入数据库值）
- 取消（保持当前编辑）

### 5. 归档保护
- `_values()` 不再硬编码 `is_archived=False`，从数据库读取当前状态
- 归档规则的保存按钮弹出警告"已归档规则无法编辑，请先点击恢复"
- 恢复后默认为停用状态（is_enabled=False）

### 6. 列表中文显示
列表格式改为：`[状态前缀] 名称 | 条件中文 | 方向/类型 数值 币种`

## 测试/验证

规则编辑器使用中文界面，不再要求用户输入英文代码。
