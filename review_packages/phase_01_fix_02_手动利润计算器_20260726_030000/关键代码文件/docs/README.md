# 微智能商品利润管理 v0.1 — 运行说明

## 一、环境要求

- **Python 3.10+**（Windows 自带 tkinter 即可）
- **无需安装任何第三方库**，仅使用 Python 标准库（tkinter, sqlite3, json, uuid, datetime）

## 二、启动方式

1. 打开命令提示符（cmd）或 PowerShell，进入项目目录：
   ```
   cd "E:\EcommerceSkills\Profit accounting-Auto"
   ```

2. 运行：
   ```
   python app.py
   ```

3. 如果系统中 `python` 指向 Python 3，也可以双击 `app.py`（取决于系统关联）。

## 三、界面说明

启动后显示两个标签页：

### 1. 新商品测算

- **基本信息**：商品名称、商品成本（元）、发往义乌运费（元）
- **裸件数据**：裸重、裸长/宽/高 （本阶段仅供记录，不参与计算）
- **包装数据**：包装后重量、长/宽/高（手动填写，参与物流计算）
- **物流费用**：固定服务费、尾程费用（默认从配置读取，可手动修改）
- **售价与利润**：
  - SHEIN 二次核价
  - 当前售价人民币 / 美元（双向联动）
  - 目标利润率 (%)
  - 推广预留比例 (%)
- **备注**：自由文本

**计算结果**（右侧面板自动更新）：
- 体积重、计费重量、头程费用
- 总物流成本、总成本
- 利润金额、利润率、建议售价、折合美元

**操作按钮**：
- **新建**：清空表单，开始新商品
- **保存**：保存到 SQLite 数据库（首次保存会创建快照用于还原）
- **还原**：恢复到首次保存时的数据
- **清空**：清空表单（不删除数据库记录）
- **计��结果**：手动触发全部重新计算

### 2. 历史记录

- 显示所有已保存商品列表
- 搜索框支持按名称或商品ID搜索
- **打开**：选中记录后点击，切换到测算页面编辑
- **删除**：确认后删除商品及其快照
- 双击列表行也可打开

### 3. 设置

菜单栏 → 设置 → 汇率与费用设置：
- 汇率（1 USD = ? RMB）
- 头程单价（元/kg）
- 固定服务费（元）
- 默认尾程费用（元）

修改后自动保存到数据库，下次启动无需重新填写。

## 四、计算逻辑

| 步骤 | 公式 |
|------|------|
| 体积重 | 长(cm) × 宽(cm) × 高(cm) ÷ 8000 |
| 计费重量 | max(包装后重量, 体积重) |
| 头程费用 | 计费重量 × 头程单价 |
| 总物流成本 | 头程费用 + 固定服务费 + 尾程费用 |
| 总成本 | 商品成本 + 发往义乌运费 + 总物流成本 |
| 利润金额 | 售价人民币 - 总成本 |
| 利润率 | 利润金额 ÷ 售���人民币 × 100% |
| 建议售价 | 总成本 ÷ (1 - 目标利润率% - 推广预留比例%) |
| 人民币→美元 | 人民币 ÷ 汇率 |

**双向联动规则**：
- 修改**售价人民币**→ 自动更新利润、利润率、美元价格
- 修改**美元价格**→ 自动转换为人民币，再计算利润和利润率
- 修改**目标利润率**→ 自动计算建议售价、更新美元价格
- 修改**推广预留比例**→ 按最后一次修改方向重新计算

## 五、数据存储

- 数据库文件：`data/profit_accounting.db`（SQLite）
- 配置表 `config` 存储汇率和物流参数
- 商品表 `products` 存储所有商品数据
- 快照表 `product_snapshots` 存储首次保存时的数据
