# 运行说明 — phase_01 手动利润计算器

## 面向用户的操作指南

### 一、安装依赖

**无需安装任何第三方软件或库。**

本软件仅使用 Python 自带的 tkinter 和 sqlite3，只要你的电脑上安装了 **Python 3.10 以上版本**即可直接运行。

检查 Python 是否已安装：
```cmd
python --version
```
如果显示 `Python 3.10.x` 或更高版本，说明可以运行。

### 二、启动软件

1. 打开命令提示符（按 `Win + R`，输入 `cmd`，回车）

2. 进入软件目录：
```cmd
cd "E:\EcommerceSkills\Profit accounting-Auto"
```

3. 启动软件：
```cmd
python app.py
```

4. 也可以直接双击 `app.py` 文件启动（取决于系统文件关联设置）。

### 三、主入口文件

```text
E:\EcommerceSkills\Profit accounting-Auto\app.py
```

### 四、如何使用

#### 新建商品

1. 点击「新商品测算」标签页
2. 填写商品名称（必填）
3. 填写商品成本、包装重量和尺寸
4. 填写售价人民币或目标利润率
5. 右侧自动显示计算结果
6. 点击「保存」

#### 查看历史记录

1. 点击「历史记录」标签页
2. 在搜索框输入关键词筛选
3. 双击某条记录打开编辑
4. 修改后点击「保存」更新

#### 修改汇率和费用

1. 菜单栏 → 设置 → 汇率与费用设置
2. 修改汇率、头程单价、固定服务费、默认尾程费用
3. 点击「保存」
4. 设置自动保存，下次启动无需重新填写

#### 还原数据

- 点击「还原」按钮可将已保存商品恢复到首次保存时的数据
- 新商品（未保存）点击「还原」无效果

#### 删除商品

1. 在历史记录页面选中商品
2. 点击「删除」
3. 确认后不可恢复

### 五、数据保存位置

```text
E:\EcommerceSkills\Profit accounting-Auto\data\profit_accounting.db
```

这是一个 SQLite 数据库文件。所有商品数据、配置都保存在这个文件中。

- 软件关闭后数据不会丢失
- 如需备份，直接复制 `data` 文件夹即可
- 如需迁移到另一台电脑，复制整个 `Profit accounting-Auto` 文件夹即可

### 六、配置文件位置

配置（汇率、费率）保存在 SQLite 数据库的 `config` 表中，没有单独的配置文件。

默认值：
| 配置项 | 默认值 |
|--------|--------|
| 汇率 | 7.20 |
| 头程单价 | 100.00 元/kg |
| 固定服务费 | 36.00 元 |
| 默认尾程费用 | 0.00 元 |

### 七、常见错误及处理方法

| 错误 | 原因 | 处理方法 |
|------|------|----------|
| `No module named 'tkinter'` | Python 安装时未包含 tkinter | 重新安装 Python，确保勾选 tcl/tk |
| 无法启动，窗口一闪而过 | Python 路径问题 | 在命令行中运行，查看错误信息 |
| 计算结果全是「数据不足」 | 未填写必要字段（如包装尺寸） | 填写包装后长宽高和重量即可 |
| 售价和利润率字段自动跳变 | 正常的双向联动 | 修改哪个就按哪个方向计算，不会死循环 |
| 商品ID不记得了 | — | 在历史记录搜索框输入商品名称即可找到 |
