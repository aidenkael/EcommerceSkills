# 阶段完成总结 — phase_01 手动利润计算器

## 一、本阶��目标

开发 v0.1 单SKC手动利润计算器的最小可用版本，完成以下闭环：

> 新建商品 → 手动填写数据 → 自动计算 → 保存记录 → 关闭软件 → 重新打开 → 找到记录 → 修改并再次保存

要求**不接入 AI、不识别图片、不调用1688、不开发历史相似、不开发Excel导入导出、不开发多SKC和模型自动校准**。

## 二、实际完成的功能

### 1. Windows 桌面界面
- 使用 tkinter 实现（Python 标准库，无需额外安装）
- 双标签页：新商品测算 + 历史记录
- 菜单栏：设置 → 汇率与费用设置
- 界面简洁可用，不追求美观

### 2. 手动输入字段（20项）
| 分类 | 字段 |
|------|------|
| 基本信息 | 商品名称、商品成本、发往义乌运费 |
| 裸件数据 | 裸重、裸长/宽/高 |
| 包装数据 | 包装后重量、长/宽/高（手动填写） |
| 物流费用 | 固定服务费（默认36元）、尾程费用（可修改） |
| 售价利润 | SHEIN二次核价、售价人民币、售价美元、目标利润率、推广预留比例 |
| 其他 | 备注 |

### 3. 自动计算功能
全部计算已验证准确：

| 计算项 | 公式 | 状态 |
|--------|------|------|
| 体积重 | 长×宽×高÷8000 | ✅ |
| 计费重量 | max(包装重, 体积重) | ✅ |
| 头程费用 | 计费重×头程单价(默认100元/kg) | ✅ |
| 总物流成本 | 头程+固定服务费+尾程 | ✅ |
| 总成本 | 商品成本+义乌运费+总物流 | ✅ |
| 利润金额 | 售价−总成本 | ✅ |
| 利润率 | 利润÷售价×100% | ✅ |
| 建议售价 | 总成本÷(1−目标利润率−推广预留比例) | ✅ |
| 人民币↔美元 | 汇率换算 | ✅ |

### 4. 售价/利润率双向联动
- 修改**售价人民币**→自动更新利润、利润率、美元价格
- 修改**美元价格**→转换人民币后重新计算
- 修改**目标利润率**→自动计算建议售价
- 修改**推广预留比例**→按最后一次方向重新计算
- 通过 `_last_modified` 变量追踪用户最后操作，避免死循环

### 5. 本地数据保存（SQLite）
**三张表**：
- `products` — 商品主表（22个字段，含 image_path 预留）
- `product_snapshots` — 首次保存快照（用于还原）
- `config` — 键值对配置（汇率、费率等）

### 6. 历史记录
- 列表展示（名称、成本、售价、利润率、更新时间的 Treeview）
- 搜索（按名称或商品ID）
- 双击打开编辑
- 删除前确认
- 修改后可再次保存

### 7. 配置持久化
- 汇率、头程单价、固定服务费、默认尾��费用存 SQLite config 表
- 关闭软件后重启，无需重新填写
- 可在设置对话框修改

### 8. 输入校验
- 空字段 → 返回 None，"数据不足"，不崩溃
- 非数字 → `_safe_float` 捕获，返回 None
- 负数 → 返回 None
- 汇率为零 → 返回 None，不除以零
- 利润率+推广 ≥ 100% → 返回 None，"数据不足"
- 仅填写部分长宽高 → 体积重返回 None，其余继续计算

## 六、已知问题

1. **无法自动截图**：Agent 在无 GUI 环境下运行，无法截取 tkinter 界面截图。需要人工补充。
2. **鼠标滚轮在输入区域可能无效**：Canvas 滚动绑定使用 `bind_all`，可能与其他组件冲突。不影响核心功能。
3. **USD 价格编辑时可能存在精度问题**：用户修改 USD 价格后，程序先转 RMB 再计算。如果用户同时修改 RMB 和 USD，以最后一次修改为准。
