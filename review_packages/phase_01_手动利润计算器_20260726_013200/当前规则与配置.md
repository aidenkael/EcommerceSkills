# 当前规则与配置 — phase_01

## 一、汇率规则

- **当前汇率**：7.20 (1 USD = 7.20 RMB)
- **存储位置**：SQLite config 表，key=`exchange_rate`
- **可修改**：菜单 → 设置 → 汇率与费用设置
- **取值规则**：必须 > 0，否则货币换算返回 None
- **公式**：USD = RMB ÷ 汇率；RMB = USD × 汇率

## 二、体积重公式

- **公式**：体积重(kg) = 长(cm) × 宽(cm) × 高(cm) ÷ 8000
- **除数**：8000（硬编码在 `calculation/logistics.py`）
- **输入要求**：三个维度必须全部填写且 ≥0，否则返回 None
- **注意事项**：使用包装后尺寸计算，不是裸件尺寸

## 三、头程费率

- **当前费率**：100.00 元/kg
- **存储位置**：SQLite config 表，key=`head_haul_rate`
- **可修改**：菜单 → 设置
- **公式**：头程费用 = 计费重量 × 头程单价
- **计费重量**：取包装后实际重量与体积重的高值

## 四、固定服务费

- **当前金额**：36.00 元/单
- **存储位置**：SQLite config 表，key=`fixed_service_fee`
- **可修改**：在测算页面直接修改，或通过设置 → 修改默认值
- **说明**：表单中默认填入配置值，用户可逐单修改

## 五、尾程费用

- **当前默认**：0.00 元
- **存储位置**：SQLite config 表，key=`default_tail_haul`
- **可修改**：在测算页面直接修改，或通过设置 → 修改默认值
- **说明**：不同商品尾程费用不同，默认值仅用于初始化

## 六、利润率计算

- **公式**：利润率(%) = (售价人民币 − 总成本) ÷ 售价人民币 × 100
- **总成本** = 商品成本 + 发往义乌运费 + 总物流成本
- **总物流成本** = 头程费用 + 固定服务费 + 尾程费用
- **亏损**时利润率为负数
- **售价 ≤ 0** 时利润率为 None（无法计算）

## 七、建议售价反算

- **公式**：建议售价 = 总成本 ÷ (1 − 目标利润率% − 推广预留比例%)
- **限制**：目标利润率 + 推广预留比例 < 100%，否则无法定价
- **用途**：输入目标利润率和推广比例后，自动计算最低售价

## 八、推广预留计算方式

- 推广预留比例是一个百分比
- 仅参与**建议售价反算**，不影响实际利润计算
- 实际利润 = 售价 − 总成本（推广预留作为"预留预算"，不直接从利润中扣除）
- 公式：建议售价 = 总成本 / (1 − 利润率% − 推广预留比例%)

## 九、空值处理方式

- 缺失的数值字段 → 计算返回 None → 界面显示「数据不足」
- 缺失的字符串字段 → 默认为空字符串（名称）或配置默认值（费用）
- **缺失不影响已填字段的计算**（如只填了重量没填尺寸 → 体积重为「数据不足」，但重量仍参与计费重量计算）
- 保存时空值以 NULL 存入数据库

## 十、数据优先级

1. 用户手动输入 > 自动计算结果
2. 最后修改的关键字段决定计算方向（售价→利润率 或 利润率→售价）
3. 推广预留比例变更按最后一次方向重新计算
4. 还原功能：首次保存快照 > 当前编辑数据
