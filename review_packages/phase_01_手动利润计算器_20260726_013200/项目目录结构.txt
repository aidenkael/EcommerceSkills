# 项目目录结构

```
Profit accounting-Auto/
├── app.py                       # 程序主入口
├── requirements.txt             # 依赖声明（无外部依赖）
├── calculation/                 # 计算模块层
│   ├── __init__.py              # 导出 logistics, profit, currency
│   ├── logistics.py             # 体积重、计费重、头程、物流成本
│   ├── profit.py                # 总成本、利润、利润率、反算售价
│   └── currency.py              # 人民币↔美元换算
├── database/                    # 数据库模块层
│   ├── __init__.py              # 导出 DatabaseManager
│   └── db_manager.py            # SQLite 建表、CRUD、快照、配置
├── config/                      # 配置模块层
│   ├── __init__.py              # 导出 ConfigManager
│   └── config_manager.py        # 汇率/费率配置读写
├── ui/                          # UI 界面层
│   ├── __init__.py              # 导出 MainWindow
│   ├── main_window.py           # 主窗口 + 菜单 + 设置对话框
│   ├── product_page.py          # 新商品测算页面（核心）
│   └── history_page.py          # 历史记录页面
├── tests/                       # 测试层
│   ├── __init__.py
│   ├── test_logistics.py        # 物流计算测试 (14项)
│   ├── test_profit.py           # 利润计算测试 (18项)
│   ├── test_currency.py         # 货币换算测试 (11项)
│   └── test_database.py         # 数据库测试 (9项)
├── data/                        # 运行时数据
│   └── profit_accounting.db     # SQLite 数据库（已创建，含默认配置）
├── logs/                        # 日志目录（预留）
└── docs/                        # 文档
    └── README.md                # 运行说明
```

## 排除的目录

按验收包要求未包含：
```
.venv/                          虚拟环境
__pycache__/                    编译缓存
.git/                           Git仓库
.pytest_cache/                  测试缓存
```
