# 本阶段修改文件清单

## 新增文件

### 1. `Profit accounting-Auto/app.py` — 程序入口
- **作用**：初始化数据库、配置管理器、创建主窗口并启动 tkinter 事件循环
- **修改内容**：全新创建
- **原因**：用户指定的项目入口文件

### 2. `calculation/__init__.py` — 计算模块导出
- **作用**：统一导出 logistics、profit、currency 三个子模块
- **原因**：模块化结构要求

### 3. `calculation/logistics.py` — 物流计算
- **作用**：体积重（÷8000）、计费重量（取高值）、头程费用（×单价）、总物流成本（累加）
- **修改内容**：全新创建，4个纯函数
- **原因**：核心物流规则必须独立为模块

### 4. `calculation/profit.py` — 利润计算
- **作用**：总成本（累加）、利润金额（售价−成本）、利润率（利润÷售价×100%）、建议售价（成本÷(1−利润率−推广比例)）
- **修改内容**：全新创建，4个纯函数
- **原因**：核心利润规则必须独立为模块

### 5. `calculation/currency.py` — 货币换算
- **作用**：人民币→美元（÷汇率）、美元→人民币（×汇率）
- **修改内容**：全新创建，2个纯函数
- **原因**：汇率规则必须独立，方便以后配置化

### 6. `database/__init__.py` — 数据库模块导出
- **作用**：导出 DatabaseManager
- **原因**：模块化结构

### 7. `database/db_manager.py` — SQLite 管理
- **作用**：
  - 建表：products（22字段）、product_snapshots、config
  - CRUD：创建、更新、获取、删除商品
  - 快照管理：首次保存快照、读取快照（不覆盖）
  - 配置管理：键值对读写
- **修改内容**：全新创建
- **原因**：本地持久化核心模块，与 UI 完全分离

### 8. `config/__init__.py` — 配置模块导出
- **作用**：导出 ConfigManager
- **原因**：模块化结构

### 9. `config/config_manager.py` — 配置管理器
- **作用**：对 DatabaseManager 配置功能的轻量封装，提供 exchange_rate、head_haul_rate、fixed_service_fee、default_tail_haul 便捷属性
- **原因**：配置层独立，方便后续扩展（如支持配置文件替代数据库）

### 10. `ui/__init__.py` — UI 模块导出
- **作用**：导出 MainWindow
- **原因**：模块化结构

### 11. `ui/main_window.py` — 主窗口
- **作用**：
  - tk.Tk 主窗口创建（1050×700，最小 900×600）
  - 菜单栏：设置 → 汇率与费用设置
  - ttk.Notebook 双标签页绑定
  - 设置对话框（汇率、头程单价、固定服务费、尾程）
- **原因**：主窗口框架与设置功能

### 12. `ui/product_page.py` — 新商品测算页面（核心）
- **作用**：
  - 左侧：20+ 输入字段（基本信息/裸件/包装/物流/售价利润/备注）
  - 右侧：计算结果实时显示（体积重/计费重/头程/物流/成本/利润/利润率/建议售价/美元）
  - 底部按钮：新建/保存/还原/清空/计算结果
  - 双向联动：售价↔利润率通过 `_last_modified` 追踪防循环
  - 输入校验：`_safe_float` 安全解析，`_programmatic` 标记防止 trace 循环
- **修改内容**：全新创建
- **原因**：核心业务页面

### 13. `ui/history_page.py` — 历史记录页面
- **作用**：
  - 搜索框（按名称/ID）
  - Treeview 列表（ID/名称/成本/售价/利润率/更新时间）
  - 打开/删除 按钮，双击打开
  - 删除前确认对话框
- **原因**：历史管理功能
