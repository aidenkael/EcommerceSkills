# Windows GUI 验收清单（Phase 1.5）

## 运行方式

源码运行：

```powershell
cd "E:\EcommerceSkills\Profit accounting-Auto"
python app.py
```

或双击 `build_windows.bat`，完成后运行：

```text
dist\ProfitAccountingAuto.exe
```

打包版数据库固定保存在：

```text
%LOCALAPPDATA%\ProfitAccountingAuto\profit_accounting.db
```

## 必测项目

### 1. 设置窗口

- 可以正常打开“设置 → 汇率与费用设置”，不出现报错。
- 窗口缩放后字段仍可使用。
- 新增 20 个货代后可通过滚轮查看全部货代。
- 修改名称、头程单价、固定服务费、体积重除数和启用状态后，保存并重新打开，数值不丢失。

### 2. 归档、删除、恢复

- 新增一个未用于商品的测试货代，点击“归档/删除”，提示永久删除，确认后从列表消失。
- 新增另一个货代并保存一条商品，再点击“归档/删除”，提示归档而不是删除。
- 已归档货代不再出现在新商品的货代下拉框。
- 在“已归档”页恢复货代后，货代回到使用中列表但保持停用。
- 勾选启用并保存后，该货代重新出现在新商品下拉框。
- 使用该货代保存的历史商品仍显示保存时的货代名称和冻结费用。

### 3. 备份与恢复

- 通过“设置 → 备份全部数据”生成 `.db` 文件。
- 新增一条临时商品或修改汇率。
- 通过“设置 → 从备份恢复”选择刚才的备份并确认。
- 恢复后临时修改消失，备份时的商品、货代和汇率恢复。
- 当前数据库旁生成 `before_restore` 安全备份。
- 选择普通文本文件时应提示恢复失败，当前数据不变化。

### 4. 打包版重启

- 运行打包版，新增并保存一条测试商品。
- 完全退出软件后重新打开，商品仍存在。
- Windows 用户临时目录中不应保存正式数据库。

## 通过标准

以上项目全部通过，且没有窗口卡死、字段遮挡、历史商品费用被新规则静默改写，即可认定 Phase 1.5 的 Windows GUI 验收通过。
